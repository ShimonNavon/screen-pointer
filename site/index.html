Quick start

Record. Point. Leave a note.

Open Screen Pointer and enable Screen Recording in macOS System Settings → Privacy & Security → Screen & System Audio Recording. Reopen the app if macOS asks.

⌃ ⌥ RStart or stop a walkthrough
⌃ ⌥ DDraw one mark, then return to clicking
⌃ ⌥ NType a timestamped note
⌃ ⌥ CClear the on-screen marks
⌃ ⌥ HToggle the cursor ring
⌃ ⌥ PCapture one pointed-at area

⌃ means Control; ⌥ means Option. While typing a note, press Command–Return to save or Escape to cancel. Drawing temporarily intercepts a single stroke.

Connect your agent

A review you can continue.

With OpenCode installed and an image-capable model configured, “Review in OpenCode after stopping” starts a named review session. Find it in OpenCode’s session list under Screen Pointer review.

The handoff sends the timestamped notes and up to six selected frames to your configured OpenCode provider. It disables tools for that review. Your ordinary coding sessions keep their own permissions.

For other agents, connect the local MCP server and use “Copy review prompt.” The server exposes latest_recording, recording_frames and latest_point.

Build locally

Small, open source.

macOS 14+ recommended for all features. Requires Apple’s Swift command-line tools and Python 3 for the agent bridge.

git clone --branch agent-pointing \
  https://github.com/ShimonNavon/screen-pointer
cd screen-pointer
./build.sh

Open ~/Applications/Screen Pointer.app. See the README for the MCP configuration and saved-session format.

Good to know

Clear boundaries.

Can I still click and switch apps?

Yes, in normal recording mode. Drawing temporarily captures one stroke, and the note editor takes keyboard focus while you type. Recording covers the display selected at the start, not every connected monitor.

Does the agent watch the whole video?

The current handoff uses sampled images and timestamped notes, so it can miss motion between frames. MCP agents can request additional saved frames. The complete video remains on your Mac for playback; there is no live agent feed.

Where are the recordings?

Each walkthrough is saved under ~/Movies/Screen Pointer/Sessions/, with the movie, notes, frame images and metadata. The website does not receive your recordings automatically. OpenCode review shares the selected attachments with your configured model provider when enabled.

Does it record audio?

This preview records the screen without microphone or system audio. Typed notes carry your explanation.

What has been verified?

The native build and focused tests for ready/failed states and safe frame access pass. The installed control panel is shown above. Recording, note interaction and automatic agent review still need the real end-to-end test after macOS permission is enabled.
